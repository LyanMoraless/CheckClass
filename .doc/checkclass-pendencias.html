O Que É Este Documento

Levantamento feito em 2026-09-11 vasculhando o projeto inteiro — código real de backend/, frontend/ e mobile/, cruzado com .claude/skills/business-rules/ e .claude/skills/project-knowledge/references/pending-decisions.md — para separar o que é pendência de curto prazo (itens pequenos, não-bloqueantes, deixados para trás em frentes já entregues) do que é feature nova de longo prazo (ver documento irmão).

Nenhum item aqui bloqueia o funcionamento das frentes onde aparece — são gaps conhecidos, registrados pelos próprios agentes que implementaram (Backend, Frontend, QA, Project Guardian) no momento da entrega, nunca escondidos.

Nota "Titular padrão" de VIEW_DEVICE_BINDINGS não é grant automáticoConfig, não é bug

RULE-DEV-16 (coordenação + diretoria) é diretriz de configuração, não um grant automático do sistema — o admin do tenant precisa criar o permission_group correspondente. Mesmo padrão de todo o enum Permission na plataforma. Registrado aqui só para não ser lido como pendência técnica quando não é.

UX Duas convenções assumidas sem confirmação explícitaRevisão de UX

O Frontend Agent tomou duas decisões de UX sem pedir confirmação: a posição de "Meu dispositivo" na navegação, e a distinção entre InfoBanner/ErrorBanner para diferenciar oferta ambiente de cerimônia deliberada de vínculo. Nenhuma reclamação registrada até agora — item de revisão, não de correção.
